# 일상건강메이커

운동 프로그램 소개, 매거진 읽기, 기기 내 운동 기록 기능을 제공하는 반응형 정적 웹사이트입니다.

## 배포
GitHub Pages: main 브랜치의 루트 폴더에서 자동 배포합니다. 별도 설치나 빌드가 필요하지 않습니다.

## 파일
index.html, style.css, app.js, icon.svg, manifest.webmanifest, sw.js

## 서비스 범위
운동 기록은 현재 브라우저에만 저장됩니다. 삭제 및 CSV 다운로드를 지원합니다. 예약·결제·회원가입·서버 동기화는 제공하지 않습니다. 외부 사진은 Unsplash에서 로드합니다.
